A estação de trabalho definitiva para desenvolvimento assistido por IA no terminal. ⚡ Instalação & Distribuição

1. Instalação Automática

Instalação via script portátil em um único comando no terminal (Linux/macOS):

curl -sSL https://pult.2lp.in/install.sh | sh

Detecta arquitetura e instala em ~/.local/bin/pult sem dependências de root.

2. Pacotes na Banca

Binários pré-compilados e validados para as principais arquiteturas suportadas:

  • Linux x86_64: tar.gz musl estático
  • Linux ARM64: tar.gz aarch64 musl
  • Windows x64: .zip executável portátil
Baixar da Banca ➔

3. Compilação via Cargo

Compilar e instalar diretamente a partir do código-fonte na forja soberana:

cargo install --git https://gambi.2lp.in/lumen/pult.git pult-tui

Requer toolchain Rust 1.80+ instalado no ambiente.

🏗️ Arquitetura dos Crates

Extrator AST Poliglota

Utiliza tree-sitter e syn para inspecionar bases em Rust, TypeScript, JavaScript, Python, PHP e Bash, extraindo assinaturas públicas e estruturas enquanto descarta corpos funcionais, reduzindo drasticamente o consumo de tokens.

Motor Scout Local

Cliente Ollama nativo com monitoramento em tempo real de VRAM via /api/ps. Realiza triagem prévia dos blocos de código relevantes e possui fallback transparente de bypass quando o servidor local está desligado.

Streaming & Persistência

Orquestração com canais MPSC assíncronos gravando cada turno incrementalmente em disco no formato canônico Markdown em .antigravity/pult/sessions/, com proteção contra encerramento inesperado ou truncamento.

Guarda Estrita DD-TDD

Máquina de estados interativa baseada no ciclo GOST de 9 fases. Impede fisicamente modificações de código de produção durante a Fase 3 (Spec) e gera crônicas detalhadas no fechamento dos tickets.
